关于我

我的研究方向主要集中在计算机视觉和语义分割， 关注高精度像素级图像理解方法。

研究方向

全监督语义分割

研究全局上下文、局部边界、多尺度特征、 频域信息以及高精度语义分割方法。

基础视觉模型

研究 SAM、DINO、CLIP 等基础模型 在语义分割中的应用。

边界精细分割

重点研究目标轮廓、Boundary IoU、 小波和边界增强方法。

科研项目

SegMAN 复现与改进

基于 OpenMMLab / MMSegmentation 进行 SegMAN 模型复现和模块改进。

实验设置 / Experimental Setup

ADE20K：150 类；训练裁剪尺寸 512 × 512。

Cityscapes：19 类；训练裁剪尺寸 512 × 1024；单卡 batch size = 2；训练 160,000 次迭代。

Framework：PyTorch / MMSegmentation。

Research：Boundary Enhancement、Multi-Scale Haar Wavelet、Boundary-Aware Loss。

后续实验 / Ongoing Work

ADE20K 和 Cityscapes 验证实验已取得上述记录。 接下来开展同设置基准模型对比、模块消融、Cityscapes 边界指标评测， 以及模型复杂度与推理效率分析。

不同数据集及不同训练、评测协议下的 mIoU 不直接作为方法增益进行比较。
